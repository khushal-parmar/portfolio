# Portfolio Website (HTML + CSS + JS)

PHP ની જરૂર નથી. index.html ને browser માં ખોલો અથવા કોઈ પણ hosting ના public_html માં upload કરો.

- index.html          – આખું page
- assets/css/tailwind.css – Tailwind styles (compiled)
- assets/css/style.css    – custom CSS (animations, cursor, modal)
- assets/js/main.js       – JavaScript (typing effect, navbar, cursor, forms)
- assets/projects/        – project images

Icons (Lucide) અને Fonts internet થી આવે છે. Contact form: Web3Forms key index.html ના નીચેના `window.PORTFOLIO` માં છે.
